Every tweak, in plain words.

All 20 tweaks in Veyrox Tweaks 1.2.0: what each one changes, how much it matters, whether it needs a restart and how to undo it.

Showing 20 of 20 tweaks

Veyrox Tweaks asks for administrator rights when it starts, because many tweaks change system-wide settings (HKLM registry, power plans). Tweaks marked “Your user account” only change settings for the signed-in Windows user.

Change anything.
Undo everything.

  1. 1

    Back up first

    Before a tweak changes anything, Veyrox saves the original value in backup.json. If the backup can't be written, nothing is changed.

  2. 2

    Confirm what happens

    Turbo Boost lists every tweak it will enable and offers to create a Windows restore point first. Game Booster warns that unsaved work in the selected apps may be lost.

  3. 3

    Every action logged

    Each change, reset and error is written to log.txt with a timestamp, in %AppData%\VeyroxTweaks. Open it any time from Settings.

  4. 4

    Undo in one click

    The circular arrow resets a single tweak; “Reset all tweaks” restores every saved value. Without a saved value, Veyrox sets the Windows default.

  • Windows settings only

    No game files and nothing anti-cheat touches. Per-game tweaks use Windows' own start, graphics and compatibility options.

  • Booster with guard rails

    System processes, games and anti-cheat services are excluded from the Game Booster. Apps get 4 seconds to close on their own.

  • Accounts stay on this PC

    Passwords are secured with PBKDF2. “Stay signed in” keeps a token encrypted with Windows DPAPI.

  • Visibility is opt-in

    Only when you turn on “Show me online” do name, status, games and tweak count reach your home network. Never email or password.

  • Honest ratings

    Every tweak carries an impact rating. The app says it plainly: most FPS come from in-game graphics settings and the BIOS.

  • Not code-signed yet

    Version 1.2.0 has no code-signing certificate, so Windows SmartScreen may warn on first launch. Compare the SHA-256 checksum below before you run it.

    A Windows desktop app that gathers the settings that matter for gaming in one place: 20 rated tweaks, a one-click Turbo Boost, automatic game detection, a Game Booster for background apps, a live ping monitor and a dashboard with CPU, GPU, RAM and drive usage.     Windows 10 and Windows 11, 64-bit. The app declares both in its manifest and ships as a 64-bit .NET 8 build with the runtime included, so you don't need to install .NET. Some tweaks depend on hardware — hardware GPU scheduling, for example, needs a GTX 1000 / RX 5000 or newer graphics card.

    Use any Download button on this page. You get VeyroxTweaks.exe (63.4 MB) directly — no installer and no account on this website. Compare the SHA-256 checksum in the download section before you run it.

Confirm the administrator prompt. Veyrox then opens its sign-in widget, where you create a local account or sign in.

    Yes. Many tweaks write to system-wide registry keys and change power plans, which Windows only allows for administrators, so the app asks for these rights every time it starts. The Tweak Explorer shows which tweaks change system-wide settings and which only affect your user account.

    Each tweak changes one specific Windows setting; the Tweak Explorer lists every key it touches. The app is upfront about results: Windows tweaks usually bring a few percent, but smoother frame times. Most FPS come from in-game graphics settings and the BIOS.
